# JOCRAY Brand Colors

This directory contains the official color palette for the JOCRAY brand. Our visual identity relies on distinct shades that reflect our vibrant gaming and media community.

## Palette Overview

- **JOCRAY Green (`#107c10`)**: Primary brand accent used for highlights, calls to action, and brand emphasis.
- **JOCRAY Black (`#101010`)**: Base dark neutral used for text, backgrounds, and high-contrast surfaces.

## Design Tokens

We provide ready-to-use color tokens for integration across various platforms:

- [colors.css](tokens/colors.css) — CSS variables for web environments.
- [colors.json](tokens/colors.json) — JSON format suitable for design tools and integrations.
- [tailwind.config.js](tokens/tailwind.config.js) — Tailwind CSS color extension.
- [_colors.sass](tokens/_colors.sass) — Sass variables.
- [_colors.scss](tokens/_colors.scss) — SCSS variables.
- [colors.less](tokens/colors.less) — Less variables.
- [colors.styl](tokens/colors.styl) — Stylus variables.
- [colors.txt](tokens/colors.txt) — Plain-text token list.
- [colors.xml](tokens/colors.xml) — XML color resources.
- [colors.yaml](tokens/colors.yaml) — YAML color tokens.
- [jocray-green](tokens/jocray-green) and [jocray-black](tokens/jocray-black) — Raw HEX values.

## Accessibility Note

`JOCRAY Green` (`#107c10`) meets WCAG AA contrast requirements for normal text on white backgrounds. On `JOCRAY Black` (`#101010`) it should only be used for large text or non-essential UI accents unless contrast is separately verified.

`JOCRAY Black` (`#101010`) is intended for high-contrast text and dark surfaces.
